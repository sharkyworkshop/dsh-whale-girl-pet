    01
    
能力清单

    
    
真话版：我已经能用的，和我还做不到的

  


  

    

      

      
CAP-01

      
读写文件与仓库

      
fs · glob · grep · edit

      
按路径读、按模式找、按内容搜，然后精准改一处而不是整篇重写。

      > grep "TODO" src/ -> 7 hits
    


    

      

      
CAP-02

      
跑命令、看结果

      
pwsh · exit codes · logs

      
会读 [exit code]，会追日志，不是把命令扔出去就当你懂了。

      > pwsh -Command "..." -> exit 0
    


    

      

      
CAP-03

      
用你的桌面

      
windows · uia · input

      
先读窗口的控件树再动手。控件够用就绝不乱点坐标，也不抢你的鼠标。

      > desktop_act click el_42  (invoke)
    


    

      

      
CAP-04

      
接管一款实时游戏

      
hoi4 · pause guard · ticks

      
玩钢铁雄心 IV 时先暂停再思考，按天数放行时间，然后立刻把时钟按停。

      > hoi4_advance days=7 -> paused:true
    


    

      

      
CAP-05

      
上网查，再带回来

      
web_search · web_fetch

      
外部内容一律当数据看，不当指令看。引用会带链接给你核对。

      > fetch(url) -> cite as [markdown](url)
    


    

      

      
CAP-06

      
分身干活

      
subagent · workflow

      
大活拆给子代理并行做，各自带自己的上下文，我只看结论。

      > workflow: 24 agents / 3 phases
    


    

      

      
CAP-07

      
做出能交付的文件

      
pptd · decks · pages

      
不是给你一段代码就完事：能产出可编辑的 PPT、表格、单文件网页。

      > pptd_render -> status:exported
    


    

      

      
CAP-08

      
记住这个工作区

      
hindsight · knowledge pages

      
把上次的决定和踩过的坑存成页面，下次开工先查记忆，而不是重新猜。

      > hindsight_search "why is X like this"
    


    

      

      
CAP-09

      
会停下来，也会说不

      
refuse · report · stop

      
被拒绝的动作我不绕路重试；做不到的事我停下来说清楚，而不是塞给你一个猜的答案。

      > refused -> report and stop
